# 园味 · 智能园区餐饮 Agent 平台

## 项目介绍

面向园区员工和食堂运营人员的智能餐饮平台，提供 Web 员工端、微信小程序和运营管理端，覆盖菜品套餐、购物车、地址、下单支付、配送自提、退款及经营统计。结合大模型工具调用，实现自然语言点餐推荐、订单查询、经营分析与运营辅助。

## 技术栈

- **后端**：Java 21、Spring Boot 3.4、Spring MVC、MyBatis-Plus 3.5、MySQL 8、Redis 7。
- **前端**：Vue 3、TypeScript、Vite、Vue Router、微信小程序。
- **基础能力**：JWT、BCrypt、WebSocket、定时任务、微信支付、大模型 Tool Calling。
- **工程部署**：Maven 多模块、Nginx、Docker Compose。

## 技术要点

- **权限控制**：JWT 鉴权结合数据库实时角色与状态检查，隔离账号管理员、普通运营及点餐用户权限。
- **订单与库存**：通过事务、条件更新和订单状态机处理库存预占、超时取消、支付退款及并发冲突，保留成交快照。
- **缓存与通知**：Redis 缓存菜单和短期会话，事务提交后失效缓存；WebSocket 推送来单、催单与订单状态。
- **支付一致性**：支付回调验签、金额核对与幂等处理，协调关单和支付竞争，通过退款补偿处理异常到账。
- **Agent 编排**：将业务 Service 封装为白名单工具，先筛选候选再生成推荐；统一数据口径，限制上下文与调用预算。
- **写操作确认**：Agent 生成待确认操作，执行前复查身份、权限和目标状态，结合事务与幂等控制避免重复执行。
